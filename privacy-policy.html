前期元帳ビューア プライバシーポリシー

開発者：STEAM BASE　／　制定日：2026年10月3日　／　最終改定：2026年10月13日
English version below

STEAM BASE（以下「開発者」）は、Chrome拡張機能「前期元帳ビューア」（以下「本拡張機能」）における利用者の情報の取り扱いを、次のとおり定めます。

1. 取り扱う情報

本拡張機能は、利用者が操作したときに限り、次の情報を取り扱います。

情報取得元目的
会計データ（仕訳〔取引先名・摘要・メモを含む〕、勘定科目、事業者名・事業者番号、会計期間、消費税の設定〔課税方式・経理方式〕）マネーフォワード クラウド会計の公開API残高試算表・総勘定元帳・補助元帳を画面に表示するため
認証情報（クライアントID、クライアントシークレット、アクセストークン、リフレッシュトークン）利用者の入力、およびマネーフォワードの認可サーバーマネーフォワード クラウド会計のAPIに接続するため
CSVファイル（仕訳帳・総勘定元帳・残高試算表）の内容利用者が選んだファイル上と同じく、元帳を画面に表示するため
同意の記録（同意した日時）本拡張機能の画面での操作同意が済んでいるかどうかを覚えておくため

会計データの取引先名や摘要には、個人の氏名などが含まれることがあります。

2. 利用目的

取り扱う情報は、過去の会計期間の残高試算表・総勘定元帳・補助元帳を利用者の画面に表示するためだけに使います。

3. 同意

本拡張機能は、初めて使うときに、取り扱う情報・使いみち・保存先・送信先を画面に表示します。利用者が「同意して使い始める」を押すまで、会計データや認証情報の保存と送信は行いません。

4. 保存場所

上記の情報は、利用者のパソコンのChromeの中（chrome.storage.local）にだけ保存します。開発者はサーバーを運用しておらず、開発者やその他の外部サービスへ送信することはありません。

5. 通信先

本拡張機能が通信するのは、次のマネーフォワードのサーバーだけです。

  • https://api.biz.moneyforward.com （認可・トークンの発行）
  • https://api-accounting.moneyforward.com （会計データの取得）

マネーフォワードへのログインと連携の許可は、マネーフォワードのページで行います。本拡張機能が、マネーフォワードのログイン用パスワードを受け取ることはありません。

6. 第三者への提供・販売

取り扱う情報を第三者に提供、販売、譲渡することはありません。広告、信用度の評価、融資の判断、そのほか本拡張機能の目的以外の用途にも使用しません。

本拡張機能による利用者データの使用は、Chromeウェブストアのユーザーデータに関するポリシー（Limited Use〔限定的な使用〕の要件を含む）に準拠します。

7. 削除方法

  • 取得した会計データは、サイドパネルの「取得・更新」を開き、「表示中の期間データを削除」で削除できます。
  • アクセストークンとリフレッシュトークンは、サイドパネルの「取得・更新」を開き、「接続解除」で削除できます。
  • クライアントIDとクライアントシークレットを含むすべての認証情報は、設定画面の「クライアントIDとシークレットを削除（接続も解除）」で削除できます。
  • 本拡張機能をChromeから削除すると、保存したすべての情報が削除されます。
  • マネーフォワード側の連携は、マネーフォワード クラウドのアプリポータルの「連携中アプリ」から解除できます。

8. 開発者による情報の取得

開発者は、利用者の会計データや認証情報を受け取る手段を持っていません。利用状況の計測や解析も行っていません。

9. 商標について

マネーフォワード、マネーフォワード クラウドは株式会社マネーフォワードの商標または登録商標です。本拡張機能は株式会社マネーフォワードが提供・保証するものではありません。

10. 改定

このポリシーを改定するときは、このページでお知らせします。取り扱う情報・保存先・送信先を変える場合は、本拡張機能の画面でもう一度同意を求めます。

11. お問い合わせ

このポリシーに関するお問い合わせは、GitHubのIssuesページにお寄せください。Issuesは誰でも読める場所です。会計データやクライアントシークレットなどの秘密の情報は書き込まないでください。

Prior-Period Ledger Viewer (前期元帳ビューア) Privacy Policy

Developer: STEAM BASE / Effective: October 3, 2026 / Last revised: October 13, 2026

STEAM BASE (the "Developer") sets out below how the Chrome extension "前期元帳ビューア" (the "Extension") handles user information.

1. Information handled

The Extension handles the following information only when the user operates it.

InformationSourcePurpose
Accounting data (journal entries, including trade partner names, descriptions and memos; accounts; office name and office number; fiscal periods; consumption tax settings)The public API of Money Forward Cloud AccountingTo display the trial balance, general ledger and subsidiary ledger on the user's screen
Authentication information (client ID, client secret, access token, refresh token)Entered by the user, and issued by Money Forward's authorization serverTo connect to the Money Forward Cloud Accounting API
Contents of a CSV file (journal, general ledger or trial balance export)A file the user selectsTo display ledgers, as above
Consent record (date and time of consent)The user's action in the ExtensionTo remember that consent has been given

Trade partner names and descriptions in accounting data may include personal names.

2. Purpose of use

The information is used solely to display the trial balance, general ledger and subsidiary ledger of past fiscal periods on the user's screen.

3. Consent

On first use, the Extension shows what information it handles, how it is used, where it is stored and where it is sent. The Extension does not store or send accounting data or authentication information until the user presses the consent button.

4. Storage

The information is stored only inside Chrome on the user's computer (chrome.storage.local). The Developer operates no server, and the information is not sent to the Developer or to any other external service.

5. Network destinations

The Extension communicates only with the following Money Forward servers.

  • https://api.biz.moneyforward.com (authorization and token issuance)
  • https://api-accounting.moneyforward.com (retrieval of accounting data)

Sign-in and authorization take place on Money Forward's own pages. The Extension never receives the user's Money Forward password.

6. Sharing and sale

The information is not provided, sold or transferred to third parties. It is not used for advertising, for determining creditworthiness or for lending purposes, or for any purpose other than the purpose of the Extension.

The use of user data by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

7. Deletion

  • Retrieved accounting data can be deleted from the side panel: open "取得・更新" and press "表示中の期間データを削除".
  • The access token and refresh token can be deleted from the side panel: open "取得・更新" and press "接続解除".
  • All authentication information, including the client ID and client secret, can be deleted with "クライアントIDとシークレットを削除（接続も解除）" on the settings page.
  • Removing the Extension from Chrome deletes all stored information.
  • The connection on the Money Forward side can be revoked from "連携中アプリ" in the Money Forward Cloud App Portal.

8. Access by the Developer

The Developer has no means of receiving users' accounting data or authentication information, and performs no usage tracking or analytics.

9. Trademarks

Money Forward and Money Forward Cloud are trademarks or registered trademarks of Money Forward, Inc. The Extension is not provided or endorsed by Money Forward, Inc.

10. Changes

Changes to this policy will be announced on this page. If the information handled, the storage location or the network destinations change, the Extension will ask for consent again.

11. Contact

For questions about this policy, please use the GitHub Issues page. Issues are public; do not post accounting data, client secrets or other confidential information.
